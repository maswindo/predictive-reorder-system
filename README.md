# Predictive Reorder System

**Planned Project**

A future system to predict material ordering needs based on historical usage trends and seasonality.

## 📌 Project Goals

- Analyze historical order data to determine peak usage periods.
- Automatically calculate suggested reorder points.
- Integrate into Order Form Generator for predictive ordering.

## 📈 Planned Technologies

- Google Sheets
- Google Apps Script
- SQL (optional)
- Tableau (for visualization)
